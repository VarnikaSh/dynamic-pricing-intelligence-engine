# Dynamic Pricing Intelligence Engine
An AI powered pricing optimization platform using Reinforcement Learning(PPO), deamnd forecasting, inventory management, and competitor analysis.

## Features
- Dynamic pricing recommendations
- PPO Reinforcement Learning agent
- Demand forecasting
- Inventory tracking
- Competitor price monitoring
- Revenue forecasting
- Interactive dasboard

## Technologies
- Python
- Streamlit
- Stable-Baselines3
- Gymnasium
- Pandas
- NumPy
- Plotly

## Installation
pip install -r requirements.txt

## Run Application
streamlit run app.py

## Train PPO Agent
python train_agent.py
